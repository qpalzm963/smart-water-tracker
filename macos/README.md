# 小貓釣魚 — macOS 本機試用版

以使用者提供的貓咪照片與核可的繪本美術為主角。SwiftUI + AppKit 原生桌面 App，最低 macOS 14，沒有第三方套件依賴。

## 建置與開啟

需要 Xcode 15 以上或對應的 Swift 工具鏈（本次在 Xcode 26.0.1 / macOS 26.5.2 / Apple Silicon 驗證）。

```sh
cd macos
swift test
bash scripts/build-app.sh
open build/小貓釣魚.app
```

亦可直接雙擊 `build/小貓釣魚.app`。建置腳本會建立本機 ad-hoc 簽署的應用程式；目前未做 Developer ID 公證或 App Store 發布。產物使用建置 Mac 的 CPU 架構。

開發時可用 Xcode 開啟 `Package.swift`。要測試藍牙權限，請執行建置後的 `.app`，使用其 Info.plist 權限說明。

## 操作

- 啟動後出現沒有標題列、沒有固定資訊列的池塘小視窗。滑鼠移入顯示隱藏、置頂、記錄與展開按鈕；空白處可拖曳，邊緣可調整尺寸。
- 在池塘按右鍵也可開啟紀錄、魚缸、切換置頂或隱藏池塘。
- 木棧台小水杯常駐顯示今日 ml，水位代表飲水目標進度。點水杯可開啟紀錄；移上去查看距離下一次釣魚所需水量。右下角顯示可用次數，有機會時整合成「收竿 ×N」。
- 螢幕右上角水滴選單列圖示提供當日總量、目標進度、100/200/300 ml 快速記錄、自訂水量與完整視窗入口。App 不占用 Dock。
- 完整視窗提供魚缸、八種魚的收藏圖鑑、最近七天趨勢、歷史紀錄、手動紀錄刪除、JSON 匯出與杯墊設定。
- 收竿為 2.4 秒四段動作：浮標下沉 → 貓咪後仰拉竿 → 實際釣到的魚帶水花出水 → 貓咪開心伸掌，再顯示收藏卡。竹木竿具有漸細竿尖、竹節、纏線握柄與回彈；魚線跟隨魚的位置。平時保留眨眼、水波與浮標起伏。
- 成功記錄手動或杯墊即時喝水後，小水杯輕彈、水位平滑上升，並浮出「＋XX ml」於 1.5 秒內淡出；連續記錄合併水量，池塘上方不再另彈出「已記錄」提示；選單列與完整視窗仍保留記錄結果文字。歷史補傳、補水及刪除不觸發；隱藏池塘或收竿時不播放、不補播。開啟「減少動態效果」時只顯示靜態文字。
- 系統「減少動態效果」開啟時，收竿直接揭曉收藏；隱藏池塘時停止畫面更新，重新顯示不會重播或重複扣次數。魚缸中的魚會游動。
- 手動紀錄及即時杯墊喝水事件每累積 **200 ml** 產生一次釣魚機會，沒有時間間隔。例：450 ml → 2 次，餘量 50 ml。未滿 200 ml 的餘量跨日、重啟均保留；已獲得的次數不過期。
- 每個本地日最多發放 8 次，已花掉的次數仍計入每日上限。達上限當筆的超額水量與當日後續水量照常記錄，但不累積釣魚進度；隔日重新開放累積。拆成不同筆記錄不影響上限結果。
- 刪除手動紀錄只修正飲水總量，既有遊戲次數與累積進度不回溯。普通魚依既有比例抽選；雨天、雷雨、起霧有各自的限定魚池。稀有度與單次水量無關，沒有付費機制。
- 一次收竿會立即保存收藏，再播放動畫，關閉 App 不會遺失已抽到的魚。

## 完整視窗的新介面

魚缸、圖鑑、喝水紀錄及設定採用一致的繪本紙色介面。魚缸仍展示最近 12 隻魚，各自跨越大半個魚缸、緩慢改變深度並在邊緣轉身，可暫停游動並點魚查看捕獲資料；水草、石頭、小屋改為可直接預覽的水彩佈置。圖鑑可篩選已相遇／未相遇，查看首捕與最近捕獲資訊。紀錄依日期分組，七日圖表加入目標線；自訂水量與目標欄有即時範圍檢查。設定按用途分組，較長的天氣、杯墊及玩法說明可展開閱讀。

此更新不變更既有資料格式、飲水與釣魚規則。設計、生成素材提示及驗證方式見 [Design/aquarium-ui.md](Design/aquarium-ui.md)。

## 天氣與限定魚

在「設定與杯墊 → 池塘天氣」選擇台灣 22 縣市之一，選擇會保存在本機。選單列顯示目前天氣；池塘滑鼠移入後的天氣圖示與右鍵選單也能開啟設定。首次未選城市時，保留普通池塘與普通魚池。

- 天氣由 [Open-Meteo](https://open-meteo.com/en/docs) 提供，以縣市代表地點的目前氣象模型資料為準，並非定位或街道即時觀測。正常每 30 分鐘更新，可手動更新；失敗每 5 分鐘重試。Mac 喚醒時檢查是否需要更新。
- 雨天有雨絲、水面漣漪，以及固定在棧台旁遮住貓咪的傘；雷雨加深天色、增加雨勢，不閃光；起霧時呈現淡霧。隱藏池塘時暫停場景動畫，減少動態效果時呈現靜態天氣。
- 雨天（含毛毛雨、陣雨）限定「雨滴魚」，雷雨限定「雷光魚」，霧天限定「霧紗魚」。各天氣的專屬魚有 **20%** 機率，其餘 **80%** 按蜜桃／日光／薄荷／藍莓／月光的 32／28／22／14／4 比例抽選。雷雨不混入雨滴魚。
- 晴天、多雲及尚未支援特殊場景的天氣（例如降雪）只使用普通魚池；天氣標籤仍如實顯示。
- 按下收竿時鎖定當下有效天氣並保存結果；動畫途中刷新或換城市不會更換已抽出的魚。機會可保留等天氣；限定魚永久收藏，圖鑑提示條件及最近一次捕獲的城市與天氣。
- 天氣快取跨重啟保留，斷線最多沿用 2 小時；氣象資料本身超過 2 小時也會失效。顯示最近更新時間，過期後回普通池塘與魚池，仍可釣魚。切換城市立即清除舊城市天氣，忽略舊請求的遲到結果。
- 新捕獲紀錄保存所選城市及有效天氣；尚無有效天氣時不捏造天氣，既有魚的城市與天氣留空。資料維持 v2，使用可選欄位相容既有 v1/v2；已有新魚種的檔案無法由舊版 App 解碼，請保留備份後再降版。

天氣資料來源依 CC BY 4.0 標示於設定頁。此本機試用版使用 Open-Meteo 公開非商用 API；商業發行時需依供應商方案調整端點與授權。

## 藍牙與資料界線

- 使用既有 `firmware/include/BleProtocol.h` 的五個 GATT UUID；不修改韌體與後端。
- 使用者先在「設定與杯墊」搜尋並選擇裝置，才請求藍牙；已配對的裝置下次啟動嘗試重連。
- 訂閱即時及歷史事件、讀取 summary、寫入 `set_time`，再要求重播保留的事件。對 event ID 加上 peripheral ID 後持久化去重，避免即時／補傳重複計入。
- `refill` 顯示在紀錄裡，但不增加飲水量、不發釣魚獎勵。補傳喝水可補回紀錄，不另發獎勵。
- 既有韌體只在 RAM 保留最近 64 筆事件，重開機會清空。App 無法恢復硬體已遺失的事件；summary 的總量不會憑空轉成飲水紀錄。
- 未校時的事件標示為「杯墊 · 接收時間」，不假裝知道原始喝水時間。杯墊離線時仍可手動記錄；同一杯水請勿同時手動與自動記錄。
- 本版資料只保存在本機，尚未串接既有雲端帳號/API，沒有跨裝置同步。
- 藍牙通訊已依韌體原始碼實作，但尚未用實體杯墊完成端到端驗證，需在實機確認 MTU、通知與重連行為。

## 儲存與測試

資料位置：`~/Library/Application Support/CatPond/state.json`。使用原子寫入；若讀到損壞或不支援版本的資料，不覆寫原檔，畫面會顯示錯誤。魚缸與紀錄共用同一份狀態檔。

0.2.0 使用資料格式 v2。升級 v1 時保留所有紀錄、魚兒與既有次數，新水量餘額從 0 開始，舊紀錄不追溯發放。第一次儲存新版時，會先將原始 v1 檔案備份為同資料夾的 `state-v1-backup.json`。

UI 測試可隔離資料，避免增加使用者的飲水紀錄。先結束正在執行的 App，並在 `macos` 目錄執行：

```sh
CATPOND_DATA_DIR="$PWD/build/qa-data" ./build/小貓釣魚.app/Contents/MacOS/CatPond
```

原有 24 項 XCTest：17 項資料規則測試涵蓋事件去重及重啟、200 ml 累計／每日上限、一次多張次數、跨日餘量、手動與杯墊累計、補水與補傳、刪除後獎勵、收竿保存、未知時間、無效／未來事件、損壞檔案保護、裝置 ID 隔離及 v1 升級備份；3 項收竿動畫測試檢查四段動畫時間界線、魚出水時機、各段位置連續與重新開窗時的完成狀態；4 項喝水回饋測試涵蓋連續記錄合併與到期清除、即時／補傳／重複事件、隱藏與收竿期間抑制，以及儲存失敗與刪除不觸發。

已實際操作打包版驗證：純場景小視窗、水杯開啟紀錄、100 + 100 + 250 ml 累計為 2 次與 50 ml 餘量、重啟保留、收竿揭曉、魚缸收藏。

收竿更新亦已用 `build/qa-reel-animation` 獨立資料實際驗證：拉竿與抬手姿勢、竹木竿彎曲／回彈、魚出水弧線與水花、伸掌收穫和收藏卡，並確認每次捕魚只扣一次機會、測試喝水紀錄未變更。Release 建置及本機簽章驗證通過。

備份時可複製整個 `~/Library/Application Support/CatPond/` 資料夾；還原前先結束 App。建置產物、Swift 快取與上述隔離測試資料不納入 Git。

天氣新增 12 項測試，目前共 36 項；涵蓋所有天氣碼、精確抽選比例、過期／城市隔離、舊資料相容、捕獲天氣保存、城市切換競態、斷線與排程重試、API 異常資料、原生場景及素材渲染。2026-09-22 已通過全套測試、Release 建置與本機簽章，真實 Open-Meteo 請求成功。城市設定的端到端 UI 操作受自動化服務中斷阻擋；已用獨立測試資料完成狀態整合測試及原生畫面渲染。

輸出可供目視檢查的天氣、收竿與魚種預覽（只使用測試資料）：

```sh
CATPOND_QA_ARTIFACTS="$PWD/build/weather-qa" swift test --filter WeatherIntegrationTests/testRenderWeatherScenesAndAllFishAssets
```
